# TransNote 서비스 오버뷰

> 맞춤형 프롬프트 기반 회의록 자동 생성 서비스  
> 작성일: 2026.01.25

---

## 🎯 서비스 소개

**TransNote**는 음성 회의를 실시간으로 텍스트로 변환하고, 사용자가 정의한 프롬프트를 통해 원하는 형태의 회의록을 자동으로 생성하는 개인 전용 웹 서비스입니다.

### 핵심 특징
- **맞춤형 회의록**: 회의록, 강의, 세미나 등 상황에 맞는 프롬프트 선택
- **자동 생성**: 회의 종료 후 30초 내 AI가 구조화된 결과물 생성
- **개인 전용**: 본인만 접근 가능, 공유 기능 없음
- **보안 우선**: 녹음 파일 미저장, 모든 데이터 암호화

### 차별점
```
기존 서비스: 음성 → 텍스트 (단순 전사)

TransNote:   음성 → 텍스트 → [맞춤형 프롬프트] → 구조화된 회의록
                                     ↑
                          사용자가 원하는 형태로 변환
```

## 🔧 주요 기능

### 1. 맞춤형 프롬프트 시스템

#### 기본 프롬프트 (시스템 제공)
사용자는 상황에 맞는 프롬프트를 선택할 수 있습니다.

**1️⃣ 회의록 프롬프트** (기본값)
```
출력 형태:
- 안건별 구조화
- 논의 요약 (3-5개 불릿포인트)
- 결정사항
- 액션 아이템 (담당자, 마감일, 우선순위)
- 미해결 사항
```

**2️⃣ 강의 프롬프트**
```
출력 형태:
- 핵심 개념 정리
- 예시 및 실습 내용
- 주요 포인트
```

**3️⃣ 세미나 프롬프트**
```
출력 형태:
- 발표자별 주요 내용
- Q&A 정리
- 핵심 인사이트
```

#### 사용자 프롬프트 (직접 생성)
사용자는 자신만의 프롬프트를 만들 수 있습니다.

**예시: 일일 스탠드업 미팅**
```
출력 형태:
- 팀원별 진행 상황
  - 어제 한 일
  - 오늘 할 일
  - 블로커
```

---

### 2. 실시간 전사

**동작 방식:**
- 마이크를 통해 음성 입력
- 실시간으로 텍스트 변환
- 화면에 즉시 표시 (지연 < 500ms)
- 타임스탬프 자동 기록

**중요:**
- ❌ 녹음 파일은 저장되지 않습니다
- ✅ 전사된 텍스트만 암호화하여 저장

---

### 3. 메모 기능

**동작 방식:**
- 회의 중 언제든 메모 작성 가능
- 메모 작성 시점의 타임스탬프 자동 연동
- 회의 종료 시 전사 데이터와 함께 통합

**예시:**
```
[00:05:30] 전사: "이번 분기 매출이 20% 증가했습니다"
[00:05:35] 메모: "중요! 다음 분기 목표 25% 증가로 설정"

→ 최종 회의록에 전사와 메모가 함께 반영됨
```

---

### 4. AI 회의록 생성

**동작 방식:**
```
회의 종료 버튼 클릭
    ↓
[전사 데이터] + [메모] + [선택한 프롬프트]
    ↓
AI가 구조화된 회의록 생성 (약 30초)
    ↓
결과 화면 표시
```

**출력 예시** (회의록 프롬프트 적용 시)
```markdown
# 2026년 1분기 마케팅 전략 회의

**회의 일시:** 2026-01-25 14:00-15:30

## 안건 1: 신규 제품 런칭 전략
**논의 요약:**
- 타겟 고객층: 20-30대 확정
- 예산: 5천만원
- 런칭일: 3월 1일

**결정사항:**
- 3월 1일 공식 런칭 결정됨

**액션 아이템:**
| 작업 내용 | 담당자 | 마감일 | 우선순위 |
|----------|--------|--------|----------|
| 캠페인 기획서 작성 | 김마케팅 | 2026-02-01 | High |
| 인플루언서 섭외 | 이소셜 | 2026-02-05 | Medium |

**미해결 사항:**
- 예산 세부 배분은 다음 회의에서 논의
```

## 📱 사용 흐름

### 전체 워크플로우

```
1️⃣ 회의 생성
   └─ 제목 입력 (선택)
   └─ 프롬프트 선택 (선택, 기본값: 회의록)
   
2️⃣ 회의 진행 (노트 중심)
   ├─ 사용자가 직접 노트 작성 (Markdown)
   ├─ 실시간 전사 (백그라운드, 접기/펼치기 가능)
   └─ 자동 저장 (3초 디바운스)
   
3️⃣ 회의 종료
   └─ AI가 노트 + 전사를 통합하여 회의록 생성 (30초)
   
4️⃣ 결과 확인 및 편집
   └─ 회의록 조회, 인라인 편집, PDF 다운로드
```

## 🔐 보안 및 프라이버시

### 데이터 보안
- **암호화**: 전사 텍스트, 메모, 회의록 모두 AES-256 암호화
- **녹음 파일**: 저장하지 않음 (실시간 처리만)
- **개인 전용**: 본인이 생성한 회의만 접근 가능
- **공유 기능**: 없음

### 데이터 보관
- **전사 텍스트**: 암호화하여 데이터베이스 저장
- **메모**: 암호화하여 데이터베이스 저장
- **회의록**: 암호화하여 데이터베이스 저장
- **녹음 파일**: 저장하지 않음

---

### 주요 동작
- **회의 시작**: 프롬프트 기본값 자동 적용 (변경 가능)
- **노트 작성**: 사용자가 직접 Markdown 형식으로 작성
- **실시간 전사**: 백그라운드 처리, 접기/펼치기 가능
- **자동 저장**: 3초 디바운스로 데이터 손실 방지
- **회의 종료**: 확인 메시지 표시 후 AI 회의록 생성
- **회의록 편집**: 인라인 편집 가능
- **프롬프트 재생성**: 다른 프롬프트로 회의록 재생성 가능
